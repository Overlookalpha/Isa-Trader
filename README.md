# 🚀 IsaTrader

*IsaTrader* é uma plataforma profissional para trading automatizado em Forex, desenvolvida para integração com MetaTrader 5 (MT5).

## Objetivos

- 📈 Dashboard moderno
- 🤖 Robô de trading (Expert Advisor)
- 🧠 Inteligência Artificial para análise
- 🔒 Gerenciamento de risco
- 📊 Estatísticas em tempo real
- 📱 Interface responsiva
