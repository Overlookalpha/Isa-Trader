# IsaTrader

## Visão

IsaTrader será uma plataforma moderna de trading automatizado para MetaTrader 5.

O objetivo é unir:

- Robô de Trading
- Inteligência Artificial
- Dashboard Web
- Estatísticas
- Gerenciamento de risco
- Histórico
- Alertas

Tudo em uma única plataforma.

---

## Público

- Traders iniciantes
- Traders experientes
- Investidores

---

## Diferenciais

Interface moderna.

Fácil de usar.

Sem telas complicadas.

Sem aparência antiga.

Integração com MetaTrader 5.

IA para explicar todas as operações.

Dashboard online.

---

## Objetivo final

Criar uma plataforma que pareça um software profissional e não apenas um Expert Advisor.
